# Keyboard Shortcuts

The active bank's 3x4 pads map to:

```text
1 2 3
Q W E
A S D
Z X C
```

Each pad assignment is editable and persists in schema v1. Repeated key-down is suppressed, key-up
releases Gate playback, and pad keys are ignored while typing in text fields. Later transport,
sequencer, 16 Levels, Roll, and command-menu shortcuts remain deferred.
