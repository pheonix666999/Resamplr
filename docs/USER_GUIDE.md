# User Guide

PadFlow is currently at Milestone 0. The application opens an original resizable foundation window,
but sampler playback and project-editing features are intentionally unavailable. The console and GUI
headless modes are engineering diagnostics, not music-production workflows.

User-facing sampler instructions will be added with the milestone that implements each verified
feature. No exact Resamplr parity is claimed while the reference asset is invalid.
